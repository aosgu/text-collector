### 1.2 导航结构

| 导航项 | 页面/动作 | 图标 |
|--------|----------|------|
| 清单列表 | 清单工作台 | 📋 |
| + 新建清单 | 直接创建空白清单并进入 | ➕ |

### 1.3 视图定义

| 视图 | 说明 | URL 参数 |
|------|------|----------|

| 已完成 | 所有清单下已完成事项汇总 | `?view=done` |

## 2. 数据模型

### 2.1 TodoList（清单）

```javascript
{
  id: string,           // UUID v4
  name: string,         // 清单名称
  createdAt: number,    // 创建时间戳
  updatedAt: number,    // 更新时间戳
  order: number,        // 排序权重（越小越靠前）
  itemCount: number,    // 待办数量（缓存）
  completedCount: number // 已完成数量（缓存）
}
```

### 2.2 TodoItem（待办事项）

```javascript
{
  id: string,           // UUID v4
  listId: string,       // 所属清单 ID
  content: string,      // 内容文本
  completed: boolean,   // 完成状态
  order: number,        // 排序权重（越小越靠前）
  createdAt: number,    // 创建时间戳
  completedAt: number | null  // 完成时间戳
}
```

### 2.3 Template（模板）

```javascript
{
  id: string,           // UUID v4
  name: string,         // 模板名称
  items: string[],      // 事项内容数组（不含状态）
  createdAt: number,    // 创建时间戳
  updatedAt: number     // 更新时间戳
}
```

### 2.4 存储键设计

| 数据 | 存储键 | 说明 |
|------|--------|------|
| 清单列表 | `todo_lists` | TodoList[] |
| 待办事项 | `todo_item_<id>` | 单个 TodoItem |
| 模板列表 | `todo_templates` | Template[] |
| 视图状态 | URL 参数 | 通过 URL 管理 |

## 3. 交互设计

### 3.1 清单管理

| 操作 | 触发 | 系统行为 |
|------|------|----------|
| 创建空白清单 | 点击"+ 新建清单" | 立即创建"未命名清单"，进入工作台 |
| 重命名清单 | 点击清单标题 | 进入编辑状态，回车保存 |
| 删除清单 | 悬停显示删除按钮 → 点击 | 二次确认弹窗 → 删除清单及所有待办 |
| 排序清单 | 拖拽侧边栏列表项 | 实时更新排序 |

### 3.2 待办事项管理

| 操作 | 触发 | 系统行为 |
|------|------|----------|
| 添加待办 | 点击"+ 添加待办" | 列表底部插入空输入框，聚焦，Enter 保存 |
| 编辑内容 | 点击内容文本 | 进入编辑状态，回车保存，Esc 取消 |
| 完成事项 | 点击勾选控件 | 切换 completed 状态，完成的沉底 |
| 删除事项 | 悬停显示删除按钮 → 点击 | 直接删除（无确认），显示撤销 toast |
| 拖拽排序 | 拖拽事项 | 实时更新 order，完成的事项不参与拖拽 |

### 3.3 模板管理

| 操作 | 触发 | 系统行为 |
|------|------|----------|
| 存为模板 | 点击"存为模板"按钮 | 使用清单名称创建模板，复制所有事项内容 |
| 使用模板 | 悬停卡片 → 点击"使用该模板" | 创建同名新清单，复制事项为未完成 |
| 复制模板 | 模板详情区"复制模板"按钮 | 创建模板副本，名称加"（副本）" |
| 删除模板 | 悬停显示删除按钮 → 点击 | 二次确认弹窗 → 删除 |
| 重命名模板 | 点击模板名称 | 进入编辑状态，回车保存 |

### 3.4 视图切换

| 操作 | 触发 | 系统行为 |
|------|------|----------|
| 进入清单 | 点击侧边栏清单项 | 显示清单工作台 |
| 全部待办 | 点击侧边栏"全部待办" | 显示所有未完成事项汇总 |
| 已完成 | 点击侧边栏"已完成" | 显示所有已完成事项汇总 |
| 模板库 | 点击侧边栏"模板库" | 显示模板卡片列表 |

## 6. 技术实现

### 6.1 文件结构

```
text-collector/
├── todo/
│   ├── todo.html          # 待办页面入口
│   ├── todo.css           # 待办页面样式
│   ├── todo.js            # 待办页面逻辑
│   ├── todo-storage.js    # 待办数据操作
│   └── todo-render.js     # 待办渲染函数
├── utils/
│   └── storage.js         # 已有采集存储（不修改）
└── manifest.json          # 更新权限
```

### 6.2 页面入口

- 顶部"待办"按钮 → 打开 `todo/todo.html`（整页替换）
- URL 参数管理视图状态

### 6.3 样式复用

复用 `manager.css` 的 CSS 变量和组件样式：
- 按钮 `.btn` / `.btn-primary` / `.btn-danger`
- 卡片 `.card`
- Toast 通知
- 弹窗 `.modal-overlay` / `.modal`
- 颜色变量 `--blue` / `--text` / `--border` 等
- 字体 `--serif` / `--sans`

### 6.4 数据隔离

- 待办数据使用独立存储键（`todo_` 前缀）
- 与采集记录完全隔离
- 使用 `chrome.storage.local` 的 `todo_lists` / `todo_items` / `todo_templates`

## 7. 状态管理

### 7.1 应用状态

```javascript
{
  currentView: 'list' | 'all' | 'done' | 'templates',
  currentListId: string | null,
  lists: TodoList[],
  items: Map<string, TodoItem>,
  templates: Template[],
  isLoading: boolean
}
```

### 7.2 URL 状态

| URL | 视图 |
|-----|------|
| `?view=list&id=xxx` | 清单工作台 |
| `?view=all` | 全部待办 |
| `?view=done` | 已完成 |
| `?view=templates` | 模板库 |

## 8. 边界情况

| 场景 | 处理方式 |
|------|----------|
| 删除清单 | 二次确认弹窗，包含清单名称 |
| 删除模板 | 二次确认弹窗 |
| 空清单 | 显示"暂无待办事项，添加一条吧" |
| 空模板库 | 显示"还没有模板，从清单存为模板开始" |
| 删除最后一个事项 | 清单保留，显示空状态 |
| 使用同名模板 | 允许，创建同名清单（用户可后续重命名） |
| 事项内容为空 | 拒绝保存，自动移除空事项 |

## 9. 无障碍支持

- 所有交互元素可键盘访问
- `aria-label` 标注图标按钮
- `role="checkbox"` 标注勾选控件
- `aria-expanded` 标注折叠区域
- 焦点管理：模态框焦点陷阱、关闭后焦点还原
- 符合 WCAG 2.1 AA 对比度要求
